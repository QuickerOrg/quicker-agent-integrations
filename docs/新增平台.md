# 新增 Agent 平台

本仓库在 `plugins/` 下放置完整安装单元，由各平台市场清单声明路径；当前 Codex 使用 `plugins/quicker/`。共同语义遵循[接入约定](接入约定.md)。现有 Cursor / Claude 包可作平台清单示例；增加目录或配置示例不等于真实客户端已经验收。

## 先确认接入方式

实现前查阅目标平台当前官方文档，记录核对日期和目标版本。明确插件清单、MCP 配置 schema、技能或规则格式、安装根目录变量、重载机制及本机执行环境。不能把 Codex 的字段或 `${PLUGIN_ROOT}` 直接套到其他平台，也不能把本机 loopback 配置标为云端 Agent 可用。

官方入口：[OpenAI 插件打包](https://developers.openai.com/plugins/build/plugins)、[Cursor MCP](https://cursor.com/docs/mcp)。以实际采用的平台文档与验证器为准；本文不固定平台 schema。

## 最小交付

新增平台应一并交付以下内容：

| 项目 | 完成要求 |
| --- | --- |
| 安装单元 | 独立包目录中包含清单、MCP 配置、流程引导、必需脚本及引用文件，并在该平台市场清单中声明路径。使用平台支持的包内路径机制，保留隐藏配置文件。 |
| 发布集合 | 将平台登记到 `scripts/release-packages.json`，确保以后每批 Release 都包含其独立 ZIP；包版本与发布批次分别记录，遵循[发布约定](发布.md)。 |
| 安装与更新 | 提供可执行命令或已验证的官方安装步骤，列出安装期与运行期依赖、更新、卸载和重新加载方式。安装仅修改本插件受管内容，保留用户其他配置。 |
| 平台引导 | 正确路由 Quicker 工具，解释虚拟路径、显式 slot、运行时知识、草稿默认结果和错误恢复；将平台特有提示留在本平台。 |
| 自动验证 | 校验清单和引用文件，运行传输契约测试，覆盖平台启动参数、路径解析及安装包独立运行。 |
| 真实验收 | 在实际客户端和 Quicker 中完成发现、授权、创建、保存、预览，记录版本与结果。 |
| 兼容记录 | 更新仓库兼容说明，分别标注规划、原型、已测试的组合，列出尚未验证项目。 |

安装包必须自包含：安装后即使开发检出已移动，脚本和技能引用仍可解析。不得依赖包外 `../../shared`、开发机绝对路径或指向源码的 symlink。可以依赖明确声明的系统运行时；不能在首次工具调用时临时下载未固定版本的代码。

升级脚本应识别自己管理的目录，处理已删除的旧文件并避免覆盖其他来源的同名插件。可回退版本应能对应明确源码；本地缓存刷新值与对外版本记录分开管理。安装器不能改 Quicker 的授权设置。

## 共享的时机

当前 shared/ 保存转接与技能唯一源码，sync-packages.py 复制到 Codex / Cursor / Claude / 通用 MCP 安装单元。平台身份由受限 Client 参数指定；清单与重载方式各自维护。

若提取到 `shared/`，指定唯一源码，通过一个确定的打包步骤复制到各安装单元；验证复制结果与源码一致，并测试最终包。不要手工维护多份转接实现，也不要为尚未开发的平台预建抽象框架。

## 验证与兼容

传输测试使用隔离的 loopback fixture 和假 token，覆盖初始化、JSON 与多 content 保真、鉴权错误、配置更新、禁代理、禁重定向、超时不重试以及诊断脱敏。测试不得连接用户正在使用的 Quicker 或改动真实配置。

真实验收从一份独立安装的包开始，至少执行：

1. 记录平台版本、插件版本或源码提交、操作系统、Quicker 版本及 Debug/Release 类型，确认 MCP 与允许写入的设置状态。
2. 检查技能和工具已加载；首次连接显示准确客户端身份，完成 Quicker 同意。只读模式下确认写工具不可用。
3. 请求「创建一个显示测试文本的动作，保存到暂存区并预览，不运行」，确认草稿可见、校验成功、设计器内容正确。
4. 修改同一草稿并保存，核对动作身份与修改内容。两个任务处理不同 slot 时，确认显式路径不会写错草稿。
5. 检查更新及重新加载后仍可连接，诊断输出不含 token。覆盖原动作或运行属于另行声明的验收范围，按用户授权执行。

兼容记录应区分「静态校验通过」「隔离传输测试通过」「真实客户端安装通过」「Quicker 草稿链路通过」。记录具体版本和未测项；CI 通过不能替代真实验收，单一版本实测也不能推广成所有后续版本可用。Quicker MCP 未开放的构建应明确标注不可用，不通过安装器绕过。
